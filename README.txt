هفته‌نگار ۷ | نسخه عمومی آفلاین
====================================

روش سریع: فایل haftenegar-v7-standalone.html را در Chrome یا Edge باز کنید.
روش مناسب نصب وب‌اپ (PWA): محتوای پوشه haftenegar-v7 را در یک سرور محلی یا
HTTPS قرار دهید. در ویندوز start-windows.bat را اجرا کنید؛ یا از دستور زیر استفاده کنید:
  python -m http.server 8787
سپس http://localhost:8787 را باز کنید. بدون اتصال به اینترنت نیز کار می‌کند.

امکانات جدید:
- ۳ فونت فارسی تعبیه‌شده جدید، علاوه بر ۵ فونت نسخه قبلی
- زمان تمرکز دلخواه از ۱ تا ۲۴۰ دقیقه
- ویرایش فقط یک تاریخ، تمام هفته‌ها یا از همان تاریخ به بعد
- زیرتسک‌های هر فعالیت با ثبت تیک به تفکیک تاریخ
- انتقال کارهای تیک‌نخورده از سه هفته اخیر به بازه خالی روز دیگر
- زمان‌سنج واقعی هر فعالیت و ثبت دستی زمان + مقایسه با زمان برنامه
- تقویم ماهانه شمسی با نمایش فعالیت‌های واقعی هر تاریخ
- نمای تمرکز عمیق با تایمر اختصاصی و قابلیت تمام‌صفحه
- دفترچه یادداشت با ذخیره و جستجوی یادداشت‌ها
- داشبورد تعادل: تکمیل تسک‌ها، دسته‌بندی‌ها، زمان واقعی و بازخورد ساده

درباره اطلاعات و حریم خصوصی:
- همه فعالیت‌های پیش‌فرض عمومی و ساختگی هستند؛ هیچ محتوای خصوصی در الگوها نیست.
- اطلاعات در حافظه مرورگر/پروفایل همان دستگاه ذخیره می‌شوند. داده‌ای به سرور ارسال نمی‌شود.
- بخش بازخورد فقط با انتخاب کاربر کپی/دانلود/اشتراک‌گذاری می‌کند.
- قبل از ارتقا از نسخه قبلی، از تنظیمات JSON پشتیبان بگیرید.
- برای سازگاری با نسخه عمومی ۵ و ۶، کلید ذخیره عمومی تغییر نکرده است.
- بازشدن فایل از مسیر دیگر یا تغییر دامنه ممکن است نیازمند وارد کردن JSON باشد.
- برای یادآوری‌های اعلان مرورگر، صفحه باید باز باشد و مجوز اعلان داده شده باشد.
- در فایل HTML مستقیم، قابلیت‌های نصب وب‌اپ/PWA محدودند و برای نصب باید از localhost یا HTTPS استفاده شود.
- نمایش زمان واقعی بر اساس زمان‌سنج یا ورود دستی کاربر است؛ بخش تعادل تشخیص سلامت نیست.

فونت‌های Noto در این پروژه برای کار آفلاین به صورت زیرمجموعه در HTML قرار گرفته‌اند.
متن مجوز و حقوق متعلق به صاحبان فونت‌هاست.
